# Pepea Radio

Kenya's premier radio station — Sauti Ya Afrika. Live streaming, news, sports, politics, and community stories.

## Quick Start

```bash
npm install
npm run dev
```

## Setup

See [SETUP_GUIDE.md](./SETUP_GUIDE.md) for full step-by-step instructions for Vercel, Clerk, and Supabase.

## Admin Panel

- Sign in at `/sign-in`
- Admin dashboard at `/admin`
- Manage articles, schedule, reports, users, brief slider, and site settings
